# Melon's Anomaly Library

**melon 的异常库**，用于 Steeple 系列服务器活动的 Minecraft Forge 模组，包含异常物品、固定生物的工具，以及能够拟态、移动和电击的苔藓。

Minecraft **1.20.1** / Forge **47.4.20** / Java **17**。

## 异常列表

| 名称 | 注册 ID | 使用方式 | 主要特性 |
| --- | --- | --- | --- |
| 塔罗牌：战车 | `melon_anomaly:tarot_the_chariot` | 主手、副手持有，或装备在可用的 Curios 饰品槽 | 获得速度 V，向前碰撞时受到伤害 |
| 锤子 | `melon_anomaly:hammer` | 主手持锤，配合副手锚钉右键生物 | 钉住生物或拔出已有锚钉 |
| 锚钉 | `melon_anomaly:nail` | 放在副手，与锤子配合使用 | 消耗一枚固定生物，拔出后返还 |
| 单片传送眼镜 | `melon_anomaly:monocle` | 装备在头盔栏，或可用的 Curios 头部饰品槽 | 周期性尝试传送到附近指定方块上方 |
| 拟态电击苔藓 | `melon_anomaly:copycat_block` | 放置在方块表面 | 模仿方块外观、捕食肉类掉落物、游荡并使接触者触电 |

以下特性对应当前代码实现。时间按正常的 **20 tick／秒** 换算，伤害数值为代码中的基础伤害，实际扣血受游戏伤害结算影响。

## 异常特性

### 塔罗牌：战车

- 生效期间持续获得**速度 V**；仅放在普通背包中不会触发。
- 将玩家碰撞箱沿视线的水平分量向前偏移，最大偏移为 0.5 格，用于检测前方碰撞。
- 从未碰撞进入碰撞状态时，造成 **4 点伤害（2 颗心）**。持续顶住同一障碍不会每刻重复扣血，离开碰撞状态后再次撞上可重新触发。
- 撞击致死时，从两条战车专属死亡文案中随机显示一条。

### 锤子与锚钉

- **钉住与拔钉都必须主手持锤、副手持有锚钉**，然后右键目标生物；副手空着时不能拔钉。
- 钉住未固定的生物时，消耗副手 **1 枚锚钉**，造成 **2 点伤害（1 颗心）**，并记录目标当时的位置。
- 被钉住的生物发生位移时会被拉回记录位置，同时取消击退；固定状态会随实体存档保存。
- 对已固定的生物再次使用，可解除固定并返还 **1 枚锚钉**：优先叠加到副手，副手满组时放入背包，背包也无法容纳时掉落在地上。
- 创造模式下不消耗锚钉，拔钉也不额外返还，但仍需副手持有锚钉。
- 若钉住时用掉了副手最后一枚锚钉，需要重新在副手放入锚钉，才能执行拔钉。

### 单片传送眼镜

- 装备后按玩家计时，每 **200 tick（约 10 秒）**触发一次传送尝试。
- 每次最多随机检查 **50 个候选位置**，X、Y、Z 各轴相对玩家所在方块的偏移均为 **−30～+29 格**。
- 落点下方必须是以下白名单方块之一，落点及上方一格必须为空气，且玩家完整碰撞箱不能与方块重叠。

| 来源 | 可作为落点地面的方块 ID |
| --- | --- |
| SCP Lockdown | `scplockdown:white_wall` |
| SCP Lockdown | `scplockdown:ceiling` |
| SCP Lockdown | `scplockdown:wall_e` |
| SCP Lockdown | `scplockdown:floor_a` |
| SCP Lockdown | `scplockdown:grate` |

- 只检查已加载区域，并避开世界边界和建筑高度之外的位置。
- 当次没有找到有效落点时保持原位。未提供这些白名单方块的环境中，眼镜仍可装备，但不会找到有效传送落点。

### 拟态电击苔藓

- 可贴附在地面、墙壁或天花板上，厚度为 **1/16 格**。
- 放置时模仿背后所附着方块的外观。手持其他方块右键苔藓，可将外观设为该方块的默认状态；非创造模式消耗 **1 个方块物品**。
- 手动指定的外观在移动后保留；没有手动指定时，移动后改为模仿新附着的方块。
- 不在捕食冷却时，每 **10 tick（约 0.5 秒）**扫描一次，范围为苔藓所在方块的包围盒向各方向扩展 **1.5 格**。捕食对象是代码标记为肉类的可食用掉落物，每次消耗 **1 个**，随后进入 **400 tick（约 20 秒）**捕食冷却。
- 捕食后重置游荡计时，并尝试移到食物所在方块；只有目标为空气且相邻存在合适支撑方块时才能移动。
- 游荡计时达到 **1200 tick（约 60 秒）**时，尝试随机移动到周围一格内可附着的空位置；没有合适位置时保持原位。

#### 触电效果

- 生物接触苔藓时获得 **60 tick（约 3 秒）**的触电效果，持续接触会刷新时长。
- 触电期间持续施加**失明 I**与**缓慢 V**，两种附加效果每次续期 **40 tick（约 2 秒）**，因此可在触电结束后短暂残留。
- 按实体计时，每 **40 tick（约 2 秒）**造成 **2 点魔法伤害（1 颗心）**并播放电击音效。
- 玩家触电时伴随视角抖动；触电致死时随机显示一条电击专属死亡文案。

## 获取与兼容

- 当前内容可在创造模式的 **「melon的异常库」**标签页中找到，也可通过上表注册 ID 使用 `/give` 获取；仓库当前未提供合成配方或自然生成配置。
- Curios 为可选兼容：战车带有 `curios:charm` 标签，眼镜带有 `curios:head` 标签；使用饰品栏需环境提供对应可用槽位。
- 单片传送眼镜的落点规则依赖上述 SCP Lockdown 方块 ID；SCP Lockdown 未被声明为模组的强制依赖。

## 构建

将 `gradle.properties` 中的 `org.gradle.java.home` 设置为本机 Java 17 安装目录，然后运行：

```powershell
.\gradlew.bat build
```

模组 JAR 生成在 `build/libs/`。

## 回归检查

运行服务端游戏测试：

```powershell
.\gradlew.bat runGameTestServer -x downloadAssets
```

GameTest 与测试资源位于 `src/test/`，不会打包进正式模组 JAR。

苔藓渲染几何检查会随 `build` 的检查阶段执行，也可单独运行：

```powershell
.\gradlew.bat verifyCopycatGeometry
```
